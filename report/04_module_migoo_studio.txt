1. MODULE OVERVIEW
------------------

Migoo Studio is the most advanced module in the platform — it gives users
full creative control over every aspect of video production. While other
modules are fully automated (user provides a prompt, AI does everything),
Studio places the user in the director's seat with AI as their production
crew.

This module is designed for professional creators who want to:
  - Upload their own source documents (PDFs, ZIPs, images) as raw material
  - Inject custom photos and video clips per scene
  - Edit AI-generated scripts with a gamified authenticity scorer
  - Control voice settings (pace, temperature) per individual scene
  - Mix AI-generated content with their own footage
  - Choose caption styling and music per video

Production Pipeline:
  Upload Source Document → Vision AI Extraction → AI Script Generation →
  Human Script Editing (with Touch Score) → Scene Asset Assignment →
  Voice & Caption Configuration → Background Processing → Final Video

3. DOCUMENT SOURCE SYSTEM
----------------------------

Unlike other modules where the user provides a text topic, Studio allows
uploading structured source material:

  a) SUPPORTED FORMATS:
     - PDF documents (research papers, presentations, reports)
     - ZIP archives (multiple files bundled)
     - Images (diagrams, charts, infographics)

  b) VISION AI EXTRACTION:
     - Uses Sarvam Vision OCR (via /api/sarvam-doc) to extract text from
       uploaded documents
     - Supports multi-page PDFs with per-page extraction
     - Extracted content stored as contextMarkdown in shortVideoAssets
     - This extracted text becomes the source material for AI script
       generation — ensuring the video accurately represents the document

  c) CONTEXT INJECTION:
     - The extracted markdown is sent to Groq LLM along with the script
       generation prompt
     - AI generates a script that directly references the document's content
     - This enables "Document-to-Video" conversion — upload a PDF, get a
       professional video summarizing its contents


4. SCENE ASSET MANAGER
------------------------

Studio's most powerful feature — per-scene asset control:

  a) ASSET TYPES per scene:
     - 'ai_image' — Let Leonardo AI generate the scene image (default)
     - 'user_upload' — Inject your own photo or video clip
     - 'kling_video' — Use Kling AI to convert an image to video
     - 'doc_image' — Use an image extracted from the source document

  b) SCENE ASSET STRUCTURE (studioPayload.sceneAssets[]):
     Each scene asset contains:
     - type: The asset type string
     - files: Array of { url, fileId, isVideo, mimeType }
     - imgToVideoEnabled: Boolean — convert image to video clip
     - splitScreenEnabled: Boolean — split-screen layout
     - splitPairs: Array of paired assets for split view
     - docImageUrl: URL of document-extracted image

  c) LEGACY COMPATIBILITY:
     The resolveSceneAsset function in inngest/functions.ts handles both:
     - New format: studioPayload.sceneAssets[i]
     - Legacy format: studioPayload.sceneAssetTypes[] + sceneCustomUrls[]

  d) MIXED MEDIA WORKFLOW:
     Users can mix different asset types per scene:
     - Scene 1: User's company logo (user_upload)
     - Scene 2: AI-generated visualization (ai_image)
     - Scene 3: Chart from PDF (doc_image)
     - Scene 4: User's product demo video (user_upload, isVideo=true)
     - Scene 5: AI image converted to cinematic video (kling_video)
     - Scene 6: User's team photo (user_upload)


5. HUMAN TOUCH SCORE (Script Editor)
--------------------------------------

The gamified script editor encourages users to personalize AI-generated
scripts, making the content more authentic and engaging:

  a) HOW IT WORKS:
     - AI generates an initial 6-scene script from the source material
     - User can edit any scene's narration text
     - The system calculates a "Human Touch Score" based on how much the
       user has modified the AI output

  b) SCORING FACTORS:
     - Text modifications (additions, deletions, rephrasing)
     - Personal anecdotes or opinions added
     - Tone adjustments (formal → conversational, etc.)
     - Percentage of original AI text retained vs modified

  c) PURPOSE:
     - Gamifies the editing process — "Can you get 90%+ Human Touch?"
     - Encourages users to add their personality to AI content
     - Results in more authentic, engaging videos that don't sound robotic
     - Differentiates Studio output from fully automated modules


6. PER-SCENE VOICE CONFIGURATION
-----------------------------------

Studio allows granular control over voice settings for each individual scene:

  studioPayload.sceneVoiceConfigs[]: Array of per-scene settings:
  - pace: Number (0.5 - 2.0) — Speaking speed
  - temperature: Number (0.0 - 1.0) — Voice expressiveness

  This allows:
  - Slow, dramatic pace for intro scenes (pace: 0.8)
  - Normal conversational pace for body scenes (pace: 1.05)
  - Energetic, fast pace for climax scenes (pace: 1.3)
  - Low temperature for professional content (temperature: 0.3)
  - High temperature for creative storytelling (temperature: 0.8)


7. INTEGRATION WITH INNGEST PIPELINE
--------------------------------------

Studio does not have its own rendering pipeline — it leverages the existing
generateShortVideo Inngest function by passing a studioPayload:

  a) SCRIPT BYPASS:
     When studioPayload.scriptData is provided, Step 2 (AI Script Generation)
     is skipped entirely. The user's edited script is used directly.

  b) ASSET OVERRIDE:
     The resolveSceneAsset function checks studioPayload.sceneAssets[i] for
     each scene. If a custom asset exists, it overrides the default
     AI image generation for that scene.

  c) VOICE OVERRIDE:
     studioPayload.voice and studioPayload.language override series defaults.
     Per-scene voiceConfigs are applied during TTS generation.

  d) CAPTION OVERRIDE:
     studioPayload.captionStyle overrides the series default caption styling.

This design demonstrates excellent software engineering — the Studio module
reuses 100% of the existing pipeline infrastructure while adding creative
control layers on top. No code duplication.
