                    4. FEATURES & FEATURE SCOPE
================================================================================

4.1 Core Features
-----------------

1. Multi-Module AI Video Platform
   Five distinct production workflows under one unified platform:
   Video Courses, Short Videos, Motion Graphics, Studio, and AI Notes.

2. Multi-Provider AI Orchestration
   Automatic fallback between Groq LLM, Google Gemini, and OpenRouter.
   If one provider fails or rate-limits, the system transparently switches.

3. AI-Generated Scripts & Course Layouts
   Groq LLM (llama-3.3-70b-versatile) generates structured JSON outputs
   for course chapters, video scripts, scene breakdowns, and study notes.

4. Multi-Language Text-to-Speech
   Sarvam AI Bulbul v3 model with configurable voice, pace, temperature.
   Supports English, Hindi, and other Indian languages.

5. Cinematic AI Image Generation
   Leonardo AI generates photorealistic, stylized visuals per scene.
   Multiple styles: Realistic, Cyberpunk, GTA, Anime, Watercolor, etc.

6. Programmatic Video Rendering
   Remotion engine composes slides, images, audio, captions, and music
   into professional MP4 videos — no manual editing required.

7. Document-to-Content Conversion
   Upload PDFs or images, Sarvam Vision OCR extracts text, AI generates
   videos or study notes from the extracted material.

8. Word-Level Caption Synchronization
   Hormozi-style dynamic captions with word-by-word highlight animations
   and multiple styling presets.

9. Durable Background Workflows
   Inngest step-based workflows that survive server restarts. Each step
   is independently retryable — no work is lost on failure.

10. Enterprise Security Layer
    Clerk auth, IP rate limiting, CSRF protection, Zod validation,
    XSS prevention, SQL injection protection via Drizzle ORM.

11. 25+ Motion Graphic Scene Types
    Title reveals, stat counters, comparisons, kinetic text, logo reveals,
    pricing tables, testimonials, and more.

12. 6 Study Note Styles + 4 Page Designs
    Cornell, Mind Map, Flashcard, Infographic, Cheat Sheet, Timeline
    with Botanical, Abstract Pastel, Geo Pebbles, Elegant Leaf designs.

13. Clerk Google OAuth Authentication
    Secure delegated authentication — no passwords stored in database.

14. Responsive Dashboard UI
    ShadCN/UI + Tailwind CSS v4 with Framer Motion animations.
    Works on desktop, tablet, and mobile.

================================================================================
                    5. LITERATURE REVIEW
================================================================================

5.1 Traditional Video Creation Tools
-------------------------------------
Existing tools like Adobe Premiere Pro, Final Cut Pro, and DaVinci Resolve
are powerful but require significant manual expertise. They handle editing
only — users must separately source scripts, audio, images, and assets.
No AI automation exists in these traditional pipelines.

5.2 AI in Content Generation
-----------------------------
Recent advances in Large Language Models (LLMs) have demonstrated the
ability to:
  - Generate coherent, contextual scripts from minimal prompts
  - Structure content into chapters, scenes, and sections
  - Produce multi-format outputs (JSON, HTML, Markdown)
  - Maintain consistency across long-form content

Models like LLaMA 3.3 (70B parameters) achieve near-GPT-4 quality on
structured generation tasks while running at significantly faster inference
speeds on specialized hardware (Groq's LPU architecture).

5.3 Text-to-Speech Evolution
------------------------------
Method              Description                     Limitations
Concatenative TTS   Joins pre-recorded speech units  Robotic, limited voices
Parametric TTS      Statistical speech synthesis     Better but still unnatural
Neural TTS          Deep learning end-to-end         High quality, GPU-intensive
Sarvam Bulbul v3    Multilingual neural TTS          Best for Indian languages

Sarvam AI's Bulbul v3 model was selected for its superior Indian language
support, natural prosody, and configurable pace/temperature controls.

5.4 Programmatic Video Generation
-----------------------------------
Remotion (React-based) was chosen over alternatives:

Tool        Approach            Pros                    Cons
FFmpeg      CLI-based           Fast, lightweight       No complex animations
MoviePy     Python scripting    Easy                    Limited effects
Remotion    React components    Full animation control  Heavier runtime
After Effects  Manual editing   Professional            Not programmable

Remotion enables declaring video scenes as React components with full access
to CSS animations, Framer Motion, and custom rendering logic — ideal for
generating dynamic, data-driven videos programmatically.

5.5 Modern Full-Stack Architecture
------------------------------------
The combination of:
  - Next.js 16 App Router (React Server Components, streaming SSR)
  - Neon PostgreSQL (serverless, auto-scaling)
  - Drizzle ORM (type-safe SQL, zero runtime overhead)
  - Inngest (durable workflows, step functions)
  - Clerk (delegated authentication)

reflects industry best practices for building scalable, maintainable,
production-grade web applications.


================================================================================
                    6. SYSTEM OVERVIEW
================================================================================

Migoo is a full-stack AI video creation platform divided into five major
production modules, supported by a shared infrastructure layer.

6.1 Overall System Structure
-----------------------------

The project is organized into four architectural layers:

LAYER 1 — FRONTEND (Next.js 16 + TypeScript + ShadCN + Tailwind CSS v4)
  Used by:
  - Admins/Creators: Dashboard, project creation, settings
  - Video Course Generator: Course listing, chapter viewer, video player
  - Short Video Generator: Series wizard, video listing, preview
  - Motion Graphics: Chat interface, scene editor, theme selector
  - Migoo Studio: Document upload, script editor, asset manager
  - Notes Generator: Note creation form, A4 multi-page viewer, export

LAYER 2 — API ORCHESTRATION (17+ Next.js Route Handlers)
  Handles:
  - Input validation via Zod schemas
  - Authentication via Clerk middleware
  - Rate limiting (60 req/min per IP)
  - CSRF protection for mutations
  - Database operations via Drizzle ORM
  - AI provider communication
  - File upload processing

LAYER 3 — BACKGROUND WORKERS (Inngest Durable Workflows)
  Handles:
  - 7-step short video generation pipeline
  - Motion graphics asset generation and rendering
  - Long-running AI operations that exceed HTTP timeout limits
  - Automatic retry and failure recovery

LAYER 4 — DATA & EXTERNAL SERVICES
  - Neon PostgreSQL: Serverless database with 8 tables
  - Appwrite Storage: Audio, image, and video asset storage
  - Sarvam AI: TTS narration + Vision OCR
  - Groq LLM: Script and content generation
  - Leonardo AI: Image generation
  - Kling AI: Image-to-video conversion

                    7. METHODOLOGY
================================================================================

7.1 Development Methodology
-----------------------------
We followed an iterative and incremental development model. Each module
was designed, implemented, tested, and refined independently before
integration into the main platform.

7.2 Development Steps
-----------------------

STEP 1 — Requirement Gathering
  - Identified 5 distinct content creation use cases
  - Mapped user workflows for each module
  - Defined database schemas for all 8 tables
  - Selected AI providers based on quality, speed, and cost

STEP 2 — Technology Selection

Layer           Technology                  Reason
Framework       Next.js 16 App Router       SSR, API routes, React Server Components
Language        TypeScript 5                End-to-end type safety
Auth            Clerk                       Delegated OAuth, session management
Database        Neon PostgreSQL             Serverless, auto-scaling, cost-effective
ORM             Drizzle ORM                 Type-safe SQL, zero runtime overhead
Styling         Tailwind CSS v4             Utility-first, responsive design
UI Library      ShadCN/UI + Radix UI        Accessible, composable components
AI/LLM          Groq, Gemini, OpenRouter    Multi-provider orchestration
TTS             Sarvam AI (Bulbul v3)       Multi-language Indian TTS
Image Gen       Leonardo AI                 Cinematic AI visuals
Video Engine    Remotion                    React-based programmatic rendering
Storage         Appwrite                    Multi-config asset storage
Background Jobs Inngest                     Durable step-based workflows
Validation      Zod                         Runtime schema validation
Testing         Vitest                      Fast unit and integration tests
CI/CD           GitHub Actions              Automated type-check, lint, test
Animations      Framer Motion               Smooth UI transitions

STEP 3 — Database Design
  8 tables created with Drizzle ORM schema definitions:
  users, courses, chapter_content_slides, course_images,
  short_video_series, short_video_assets,
  motion_graphic_projects, motion_graphic_messages,
  notes_projects

STEP 4 — Module-by-Module Implementation
  Each module developed independently:
  Module 1: Video Course Generator (core pipeline)
  Module 2: Short Video Generator (Inngest workflows)
  Module 3: Motion Graphics Generator (chat + 25 scene types)
  Module 4: Migoo Studio (document + creative control)
  Module 5: AI Notes Generator (tiered sampling + A4 rendering)

STEP 5 — Security Implementation
  - Clerk middleware for route protection
  - IP-based sliding window rate limiter
  - CSRF origin validation
  - Zod schemas on all API endpoints
  - XSS prevention via input sanitization
  - Security headers injection

STEP 6 — Testing
  - 41 Vitest test cases across 4 test suites
  - Validation schema tests, rate limiting tests
  - API helper tests, environment config tests
  - GitHub Actions CI/CD pipeline

STEP 7 — Deployment
  - Frontend: Vercel (auto-detects Next.js)
  - Database: Neon (serverless PostgreSQL)
  - Background Jobs: Inngest Cloud
  - Storage: Appwrite Cloud

8.3 Security Architecture

Layer               Implementation              Details
Authentication      Clerk (delegated)           OAuth + email; no passwords in DB
Authorization       Route-level guards          clerkMiddleware protects all non-public
Rate Limiting       IP-based sliding window     60 req/min per IP on all API routes
Input Validation    Zod schemas                 Every endpoint validates request body
CSRF Protection     Origin header validation    Blocks cross-origin mutations
XSS Prevention      HTML entity sanitization    <script> tag detection via Zod refine
Security Headers    Middleware-injected         HSTS, X-Frame-Options, etc.
SQL Injection       Drizzle ORM parameterized   All queries use type-safe builder

Rate Limiter Implementation (middleware.ts):
  - In-memory Map<string, { count, resetTime }>
  - 60-second sliding window
  - 60 requests per window per IP
  - Automatic cleanup when map exceeds 10,000 entries
  - Returns 429 with Retry-After header when exceeded
  - X-RateLimit-Limit and X-RateLimit-Remaining headers on every response

CSRF Implementation:
  - Checks Origin header against Host header for POST/PUT/PATCH/DELETE
  - Exempts /api/inngest and /api/webhooks (internal routes)
  - Returns 403 on origin mismatch
